# JavaScript Learning Repository 📘

This repository contains all the JavaScript concepts, practice programs, and mini-projects I’ve worked on during my learning journey. It reflects my progress from **basic JavaScript** to **DOM manipulation**, **functions**, and **event handling**, including topics covered through platforms like **freeCodeCamp**, **Meta (Coursera)**, and hands-on coding.

## 🧠 Topics Covered

- ✅ Basics: Variables, Data Types, Operators
- 🔁 Control Flow: if-else, switch, loops
- 🧮 Functions: Declarations, Expressions, Arrow Functions
- 🧱 Arrays & Objects: Manipulation and Methods
- 📂 Higher Order Functions: `map()`, `filter()`, `reduce()`
- 📜 String & Array Methods
- 🎯 DOM Manipulation
- ⚙️ Event Handling
- 🧰 Local Storage
- 🧪 JavaScript Testing with Jest (basic level)
- 💡 Mini Projects (e.g., Tic Tac Toe, Theme toggler)

## 📁 Structure

- `basics/` – Fundamental syntax and beginner concepts
- `functions/` – Function creation, scope, and usage
- `dom/` – DOM manipulation examples and small projects
- `projects/` – Practice mini-projects for real-world use cases

## 💼 Purpose

This repository serves as:

- A personal JavaScript learning archive 📚
- A showcase of concepts and small applications I built 🛠
- A reference for beginners and fellow learners 👨‍💻
